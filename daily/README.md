# فيديو RAX3D اليومي

يعمل تلقائيًا كل يوم (GitHub Actions، `.github/workflows/daily-video.yml`، 08:17 بتوقيت الرياض) وينتج فيديو عموديًا (1080×1920) لمنتج من rax3d.com.

- **اختيار القطعة**: المنتجات الجديدة أولًا، ثم دورة على بقية القطع ذات المعاينة 3D دون تكرار قبل اكتمال الدورة (`state.json`).
- **النمط حسب اليوم** (توقيت الرياض): الأحد/الثلاثاء/الخميس/السبت = الفيديو الكامل، الاثنين = قلب الألوان، الأربعاء = كيف تُطبع، الجمعة = السؤال السريع.
- **الموسيقى**: مولَّدة وفريدة لكل فيديو، وسجل معلماتها `music-log.json` يمنع التكرار.
- **المخرجات** في مجلد كل يوم `YYYY-MM-DD-<id>-<mode>/`: الفيديو `.mp4` و`caption.txt` (الوصف والهاشتاقات والكلمات المفتاحية وجملة Spotlight) و`data.json`. تُحذف ملفات الفيديو والصوت بعد 45 يومًا ويبقى الوصف والسجل.
- **تشغيل يدوي** (لقطعة أو نمط معيّن): Actions ← Daily product video ← Run workflow.
- **النشر على Snapchat**: يدوي حاليًا (حمّل الفيديو من المجلد وارفعه في Stories وSpotlight مع وسم الدمام). النشر الآلي ينتظر تفعيل واجهة Snap الرسمية (Public Profile API) وحفظ مفاتيحها كأسرار في المستودع.
